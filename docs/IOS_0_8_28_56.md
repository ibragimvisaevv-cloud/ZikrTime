GitHub отдаёт каждый файл в ZIP. Для установки на физический iPhone потребуется подпись с подходящим профилем. Для полной версии профиль должен поддерживать Family Controls и группу приложения. Установка и блокировка приложений на физическом устройстве остаются непроверенными. В TestFlight и App Store сборки не отправлялись.

## Проверки

- Xcode собрал обе редакции для устройства. Проверка повторно скачала оба IPA и оба архива, сверила их контрольные суммы, архитектуру arm64 приложения и расширений, версию, dSYM, виджет, ресурсы молитв и тасбиха. В каждом варианте есть каталоги четырёх чтецов по 114 сур и отсутствуют файлы удалённой русской транскрипции. [Сборка](https://github.com/ibragimvisaevv-cloud/ZikrTime/actions/runs/44616138772) · [Проверка файлов](https://github.com/ibragimvisaevv-cloud/ZikrTime/actions/runs/44624527818)
- На симуляторе iPhone 17 с iOS 26.5 прошли три теста. Проверены вход в чтение Корана с главного экрана, выбор аята, перевод и настройки плеера, сохранение таймера фокуса после перезапуска и увеличение счётчика тасбиха на одно деление за каждое нажатие и за каждый свайп вниз. Виджет получил из общей группы приложения 315 времён намаза для Москвы в хронологическом порядке. Для этого прогона изменился только файл GitHub Actions. [Прогон симулятора](https://github.com/ibragimvisaevv-cloud/ZikrTime/actions/runs/44622990630)
- В первом прогоне на Intel прошёл тест тасбиха. Два других теста остановились при поиске счётчика фокуса и прокрутке главного экрана. Готовые архивы сохранились до этих проверок. Сценарии повторно прошли на Apple Silicon с тем же кодом приложения и тестов.
