# Продвинутый уровень 0.8.21: повествовательные вопросы

Этот модуль добавляет 40 вопросов категории `prophets`: 20 по повествованию о Юсуфе, 14 об Ибрахиме, 6 о Нухе. Он дополняет основной модуль `advanced_0821.json`; старые 40 вопросов версии 0.8.20 сохранены.

## Содержательная проверка

Все указанные аяты прочитаны в закреплённом переводе смыслов QuranEnc / Rowwad из `app/src/main/assets/quran/sources/russian_rwwad`, состояние `c592403a83b5455719b35dc1570399406e676efa`. Вопросы проверяют последовательность событий, сочетание условий, различие между репликами и конкретные детали повествования. Верный ответ и пояснение сверены с указанными аятами. Дополнительно уточнён 21 вопрос: у 20 сближены отвлекающие варианты, а один переписан для проверки сочетания обещаний в 12:6. Цель — уменьшить угадывание по общей нравственной оценке, абсурду вариантов или длине текста.

Формулировки на восьми языках являются учебным текстом приложения, а не цитатами или официальным переводом Корана. Не заявляются независимая богословская экспертиза, проверка носителями всех языков или эмпирическая калибровка сложности. Уровень 3 — редакционная классификация; корректировать его следует по реальным результатам обучения, без изменения смысла вопроса.

Учитывались контекстные ограничения:
- 12:100 описывает событие повествования, а не предписание поклонов людям.
- 19:46–47 передаёт реплики в конкретном эпизоде; не формулирует универсальное правило о молитве за любого человека.
- В 37:102 не подставляется имя сына: сам выбранный аят его не называет.
- 11:45–46 проверяет ограничение обещания в повествовании и неправедный поступок сына; вопрос не делает вывода об отсутствии биологического родства.
- Вопросы не дублируют проверяемые факты исходных 203 вопросов; 12:48–49 использует тяжёлые годы лишь как контекст для нового вопроса о следующем годе.

## Проверки структуры

40 уникальных ID с префиксом `l3n_`, уровень 3, полное покрытие ru/en/uz/tg/kk/ky/az/tr. Для каждого вопроса проверены существование всех ссылок в закреплённых файлах, четыре различных варианта и непустое пояснение не короче 20 символов. Верный вариант имеет индекс 0 в авторском модуле и перемешивается приложением. Сборщик общего банка выполняет межмодульные проверки и сохраняет старые версии содержания.
