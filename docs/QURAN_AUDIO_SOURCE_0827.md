# Источник аудио Корана 0.8.27

По прямому запросу владельца выбран один чтец: Мишари Рашид Аль-Афаси (Mishary Alafasi в каталоге MP3Quran), чтение Хафс от Асыма, муратталь. Арабский текст и файлы `assets/quran` не изменяются. Файлы аудио не упаковываются в APK.

## Источник и право использования

- [Официальная страница чтеца](https://www.mp3quran.net/eng/afs) содержит 114 сур и отдельно отмечает риваят Хафс. Другой вариант Аль-Афаси, ад-Дури, имеет отдельный набор и здесь не используется.
- [Документация публичного API MP3Quran](https://www.mp3quran.net/eng/api), [ответ для чтеца 123](https://www.mp3quran.net/api/v3/reciters?language=eng&reciter=123): `reciter.id=123`, `moshaf.id=123`, `rewaya_id=1`, `surah_total=114`, номера строго 1–114.
- [Текущая политика MP3Quran, раздел Copyrights](https://www.mp3quran.net/eng/privacy) прямо разрешает посетителям и разработчикам копировать материалы и использовать ссылки сайта. Это разрешение поставщика, а не утверждение, что любые записи Корана вообще находятся в общественном достоянии или имеют лицензию Creative Commons.
- [Контактная страница](https://www.mp3quran.net/eng/contact-us) повторяет это разрешение и предлагает ссылаться на политику для подтверждения прав. [Старый официальный адрес политики](https://www.mp3quran.net/privacy-en.html) содержит то же правило. Сообщений поставщику не отправляли.

API и политика получены прямыми HTTPS-запросами без ключа или учётной записи. Сторонние зеркала, YouTube и синтез речи не используются. Атрибуция MP3Quran и имя чтеца должны быть доступны в приложении.

## Каталог

Локальный `app/src/main/assets/quran_audio/alafasy.json` содержит только метаданные. Формат: верхние поля `reciter`, `reciter_id`, `source`, `permission_source`, `source_api`, `source_reciter_id`, `source_moshaf_id`, `rewaya`, `verified_at`; массив `tracks` из объектов `surah_id`, `url`, `size_bytes`.

Текущий официальный базовый адрес: `https://cdn.mp3quran.net/audio/mishary-alafasy/r1/`. Файлы — `001.mp3` … `114.mp3`. Старый `https://server8.mp3quran.net/afs/001.mp3` перенаправляет на этот CDN; в каталоге используются конечные HTTPS-адреса из текущего API. Никакой иной чтец не подставляется при недоступности источника.

В этой версии плеер работает с целыми сурами. Каталог не содержит непроверенных временных меток аятов и не обещает точную синхронизацию подсветки с аудио.

## Ограничения и память

Размеры `size_bytes` — снимок метаданных CDN на дату проверки, не гарантия неизменности записи в будущем. Для текущей загрузки учитываются фактический `Content-Length`, ошибки сети и нехватка места. Статус готовности офлайн требует завершения загрузки, совпадения полной длины с проверенным каталогом и наличия всех байтов в кэше; HTTP-источник принимает только `audio/mpeg`. Если поставщик изменит размер записи, потребуется проверить обновлённый источник и каталог, а не объявлять новый непроверенный файл успешно скачанным. Временный кэш и явно скачанные пользователем суры хранятся раздельно. Самая длинная сура может превышать лимит временного кэша; потоковое чтение требует кэширования фрагментов, а не обязательного размещения всей суры в 100 МБ.

Доступность проверяется из среды разработки; это не гарантия работы каждого оператора или региона. При потоковом прослушивании и скачивании устройство обращается прямо к MP3Quran: поставщик видит обычные сетевые данные запроса, включая IP. Скачанная сура должна воспроизводиться без обращения к сети. Адреса не требуют клиентских секретов. Автоматически заменять недоступные записи случайными зеркалами нельзя.
