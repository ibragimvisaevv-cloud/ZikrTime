Уточнение: пока только Android; iOS продолжать исключительно по отдельной команде. База b6862baadb77d22f3763115d68bd411a272d71ec, ветка codex/release-readiness-ios, PR #1. Не менять main, магазины и последние iOS-исправления.

Натуральная архитектура, небо, сине-серые поверхности, дымчатое стекло, умеренные тёплые акценты, каменные зелёные бусины. Не использовать отвергнутые бежевые минималистичные/мультяшные варианты. Город, время, счётчик и религиозные тексты — живые компоненты, не часть фонового изображения. Сохранить все разделы, восемь языков, офлайн-работу, настройки и прогресс. Не добавлять новые подборки азкаров.

Главная: местное время выбранного города, смена даты и возврат из фона; неподвижные небольшие ресурсы вместо непрерывной сцены. Тасбих: точный счёт при быстрых нажатиях, движение на каждый шаг, без обратного вращения на 33/99/100, корректный сброс, смена фразы и цели, остановка в покое, отключение движения согласно настройкам ОС.

Проверить: тесты периодов и движения; сборка release, подпись, размер APK/AAB с той же конфигурацией и ABI; светлая/тёмная тема, узкий экран, крупный текст, быстрые нажатия, доступные замеры кадров/памяти. Не приравнивать эмулятор к физическому устройству, не обещать экономию батареи без замеров.

Ресурсы созданы встроенным ImageGen: atlas четырёх периодов одной натуральной архитектурной сцены, без текста; отдельная сферическая бусина из тёмного серпентинового камня, прозрачный фон. В APK — только сжатые WebP (720px сцены, 128px бусина); исходники генерации в APK не входят.
