# ZikrTime 0.8.3 — тест главной и тасбиха

Только Android. Код приложения: `44d122e8870ea545001d18c289b8992b485b0d72`.

Главная получила натуральные фоны рассвета, дня, заката и ночи. Период определяется по намазам и местному времени выбранного города; встроенные 61 город имеют офлайн-часовые пояса IANA. Экран обновляется при возвращении из фона. Текст, дата, время и город остаются обычными компонентами.

Тасбих использует каменные бусины и короткое движение по нажатию. Счёт сохраняется сразу; анимация не зависит от остатка 33/99/100 и не вращается назад при новом круге. Сброс, выбор фразы и цели сохранены. Системное отключение анимаций учитывается. В этих двух экранах отключены постоянные блики, движение фоновых градиентов и датчик наклона. Нового движка нет; пять WebP занимают 221 244 байта.

## Визуальная проверка

Просмотрены реальные снимки debug-приложения на Android 15: четыре периода, светлая/тёмная тема, узкий экран 320 dp, экран с системным шрифтом 130%. При увеличенном шрифте длинная дата переносится; элементы доступны прокруткой. В тестовых снимках период принудительно выбирается через debug-параметр, поэтому вечернее небо рядом с дневным намазом не является поведением release.

40 настоящих нажатий дали увеличение 21 → 61, без потери счёта на переходе через 33. Запись движения — с эмулятора, не смонтированная анимация макета. За 5 секунд покоя после завершения движения — 0 новых кадров.

Физический телефон и расход батареи этой версии ещё не проверены. Debug-эмулятор с программным GPU не подтверждает плавность подписанного release на ARM. Проверьте установку поверх текущей версии, ощущение движения и сохранность настроек на своём телефоне.

iOS в этом задании не изменялась и не собиралась; продолжение только по отдельной команде. Main и магазины не изменены.
