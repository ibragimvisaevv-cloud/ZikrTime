# Тренировки по слабым темам — 0.8.21

## Поведение

Раздел знаний содержит компактный вход «Тренировка по темам». Отдельный экран показывает темы выбранного уровня: сколько вопросов отвечено, сколько последних ответов требуют исправления, сколько вопросов закреплено повторениями в разные дни. Полоса обозначает охват темы, не процент знания религии. Непройденные вопросы не считаются ошибками. При отсутствии истории предлагается сначала пройти обычную викторину.

Статусы основаны только на отвеченных вопросах актуальной версии. До пяти разных ответов по теме (или полного малого пула) вывод осторожный: «Мало ответов для вывода». После этого ошибки дают статус «Стоит повторить»; ответы без ошибок, но без устойчивого повторения — «Закрепляем»; не менее 80% отвеченных вопросов со stage >= 2 и отсутствие последних ошибок — «Хорошо закреплено». Это характеристика изученного материала, не всей темы.

Подход содержит не более пяти знакомых вопросов строго выбранного уровня и, если задана, темы. Вначале идут последние неправильные ответы, затем ещё не закреплённые, затем подошедшие по сроку повторения, затем остальные отвеченные. Внутри группы первыми идут давно отвеченные. Неизвестные и изменённые по смыслу вопросы не подмешиваются. После ответа доступны пояснение и источник; результат содержит разбор ошибок. Повторный немедленный правильный ответ снимает текущую ошибку, но не объявляет материал устойчиво закреплённым: прежняя интервальная политика сохраняется.

Тренировка не начисляет бонусные минуты. В личной статистике, если она включена, отмечается повторение. Обычная викторина, интервальное повторение и тренировка имеют отдельные сохранённые сеансы; смена уровня по существующим правилам завершает незаконченные сеансы, сохраняя историю и учёт награды. Если начать тренировку в другой теме при незавершённом подходе, приложение спрашивает о замене. Выход оставляет возможность продолжить; поворот/пересоздание сохраняет ответ, порядок и результат.

## Данные и защита

Используется прежний namespace learning_state_v1: questions с v/ok/at/stage/due/shown/event, новый scope sessions.training. Миграция содержательных счётчиков не выдумывается. Новый выбор не затрагивает quiz_reward_guard_v1. Результат review/training декодируется с нулевой наградой; completeCurrent не возвращает минуты для такого scope и не завершает тренировку до последнего ответа.

LearningStore.update сверяет id, scope, категорию и уровень с текущим сеансом. Обработчики переходов передают ожидаемый снимок, обработчик ответа — id отображённого сеанса; старый экран не может воскресить заменённый подход или стереть более поздний ответ. Создание нового сеанса выполняется отдельно от обновления существующего.

## Проверки

Добавлен WeakTopicPolicyTest: 12 сценариев для отсутствия данных, обновлённых/удалённых вопросов, строгого уровня/темы до ограничения длины, порядка и лимита, малой выборки, немедленного исправления, отката часов, порядка тем, восстановления ответа и перемешивания, устаревших обработчиков и нулевой награды сохранённых тренировок. Выполнение и UI-проверки отражаются в итоговом отчёте облачной сборки; этот документ сам по себе не заявляет успешный прогон.

Все 34 новые строки присутствуют в восьми локалях: values (en), ru, uz, tg, kk, ky, az, tr. Текст Корана и существующий банк вопросов этим изменением не затрагиваются.
