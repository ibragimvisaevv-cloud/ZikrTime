# ZikrTime 0.8.26 (38): инструкция по приложению

Пользователь попросил наглядное обучение при первом запуске, возможность пропустить его и повторно открыть из настроек. Озвучивание Корана и СБП на этом этапе только обсуждаются; их включение не входит в изменение.

## Поведение

После первичного выбора языка, города и необязательных разрешений новая установка показывает руководство. «Пропустить — я уже знаком», закрытие с первого шага и завершение сохраняют выбор: при следующем запуске руководство не мешает пользоваться приложением. Для уже настроенных установок при обновлении оно автоматически не открывается. Пункт «Как пользоваться» находится в начале настроек.

Десять тем: знакомство с навигацией, настройка времени намаза, отметки и история намазов, Коран и сохранённые аяты, общий лимит приложений, разрешения для ограничения, вопросы по уровню знаний, места для намаза, ежедневные инструменты, магазин и партнёры. Каждая тема содержит адаптивную схему экрана, три пронумерованных элемента и короткие действия. Иллюстрации рисуются локально и не подменяют реальные данные пользователя.

Доступны «Назад», «Далее», оглавление и закрытие. В повторном просмотре «Открыть раздел» ведёт в настоящий экран, откуда можно вернуться к той же странице инструкции. Темы и прокрутка сохраняются при повороте. Чтение инструкции не меняет город, ограничения, отметки, разрешения или учебный прогресс. Тексты — на восьми языках. Новых библиотек, сетевых загрузок и постоянных анимаций для руководства нет.

## Следующий этап: аудио Корана (пока не реализован)

В APK достаточно плеера и небольшого каталога. Проверенные записи с разрешённым использованием могут загружаться потоково с CDN; пользователь отдельно выбирает суры для постоянного офлайн-хранения. Временный кэш ограничен, например 100 МБ, и очищает старые записи; скачанное пользователем хранится отдельно до удаления. Нужно показывать размер загрузки, управление памятью и возможность загружать только по Wi-Fi.

Воспроизведение полной суры с проверенными временными метками позволяет выделять и повторять аяты без обязательной упаковки тысяч файлов в приложение. Нужны сохранение позиции, управление с заблокированного экрана и согласование с азаном, звонками и аудиофокусом. ИИ-синтез священного текста не предлагается. Наличие файла в API не подтверждает права на его распространение.

Расчётный пример без накладных расходов: 64 кбит/с — 28,8 МБ в час; условные 30 часов — 864 МБ. Это не измерение выбранного чтеца. Небольшой установочный файл совместим с большим аудиокаталогом, поскольку каталог хранится в облаке, а скачанные записи занимают дополнительную память.

Официальные технические источники: [ограниченный кэш Android Media3](https://developer.android.com/media/media3/exoplayer/network-stacks), [постоянные загрузки](https://developer.android.com/media/media3/exoplayer/downloading-media), [фоновое воспроизведение](https://developer.android.com/media/media3/session/background-playback), [аудиокаталог Quran Foundation](https://api-docs.quran.com/docs/sdk/javascript/audio/).

## Следующий этап: СБП (пока не включён)

Состояние подготовленной интеграции — в docs/DESIGN_USABILITY_0823.md и shop-bot/README.md. Robokassa предлагает подключение самозанятых без ИП и СБП. До реального запуска нужны подтверждённый НПД, одобренный магазин с описанием размещения/продвижения, оферта и контакты, активный СБП, связь Робочеков СМЗ с «Моим налогом», рабочие секреты и проверка полного платёжного сценария. Комиссию сверять по конкретному одобренному тарифу; бесплатные чеки не означают бесплатный приём платежей.

Сервер задаёт 200 ₽ за размещение карточки; продвижение — отдельный заказ. Услуга активируется только после проверки подписи серверного уведомления, суммы и заказа. Повторное уведомление не должно повторно выдавать услугу. Для цифровых услуг внутри Telegram действуют требования Telegram Stars: наличие внешнего сайта не делает СБП допустимым способом такой оплаты внутри Mini App. Канал покупки и размещение оплаты согласовать до включения.

Официальные источники, проверены 8 ноября 2026 по времени пользователя: [самозанятые в Robokassa](https://robokassa.com/solutions/business/samozanyatye/), [Робочеки СМЗ](https://robokassa.com/online-check/robocheck-smz/), [создание платежа](https://docs.robokassa.ru/ru/pay-interface), [подтверждение оплаты](https://docs.robokassa.ru/ru/notifications-and-redirects), [Telegram Stars](https://core.telegram.org/bots/payments-stars).
