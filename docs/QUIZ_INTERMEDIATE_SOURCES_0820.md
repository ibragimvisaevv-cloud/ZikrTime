# Средний уровень: источники вопросов 0.8.20

Подготовлено 40 новых вопросов по уровню 2, каждый с четырьмя вариантами, пояснением и восемью локализациями: ru, en, uz, tg, kk, ky, az, tr. Правильный вариант хранится первым и перемешивается приложением.

## Метод и границы проверки

Все 41 используемых аятов из 16 сур прочитаны в закреплённом переводе смыслов QuranEnc / Rowwad: `app/src/main/assets/quran/sources/russian_rwwad/<сура>.json`. Для каждого вопроса сверены правильный ответ, объяснение и отсутствие второго подходящего ответа. Это собственные краткие формулировки приложения; арабские строки и источники Корана не менялись.

Первоначальные 40 русских вопросов прошли отдельную текстовую сверку. После неё в 14 заданиях уточнены формулировки и сближены варианты ответа; эти изменения перенесены во все восемь локалей. Вопрос о 4:43 заменён новым вопросом `l2_good_deed_multiplied` по 4:40, чтобы не создавать неверного практического вывода о допустимости опьянения. В вопросе по 5:96 речь явно идёт об охоте, а не о любом употреблении мяса.

Религиозная экспертиза учёным и профессиональная проверка носителями всех восьми языков не проводились; такие статусы не присваиваются. Наличие ссылки на первоисточник не считается экспертным рецензированием.

## Онлайн-сверка

Дата работы: 2026-11-02. При первоначальном составлении сохранён журнал 41 ответа API QuranEnc: их тексты совпали с закреплёнными файлами. После замены 4:43 этот журнал подтверждает 40 сохраняющихся аятов финального набора. Прямые страницы QuranEnc местами недоступны веб-инструменту или отвечают HTTP429; успешное открытие страниц не заявляется для каждого адреса.

Новый аят 4:40 дополнительно сверён по официальному порталу Diyanet: [Ниса, 40](https://kuran.diyanet.gov.tr/tefsir/Nis%C3%A2-suresi/533/40-ayet-tefsiri). Он подтверждает отсутствие даже малейшей несправедливости и приумножение добра. В первоначальной работе также были открыты страницы QuranEnc для 2:260, 2:283, 3:159 и 24:58. Полная сверка каждого вопроса опирается на локальный закреплённый текст.
