# Тёмные материалы RuStore 0.8.17

Для карточки использовать утверждённую иконку «Купол и горизонт» из `design/widgets-0812/icons/02-dome`. Её экспорт 512×512 RGB находится в `store/rustore/icon-512.png`; прежняя иконка в этой папке заменена.

Подготовлены шесть реальных снимков Android 15 в тёмной теме: главный экран, Коран с переводом, полноэкранный Коран, статистика чтения, тасбих и короткая сура. Размер каждого — 1080×1920. Снимки сделаны из уже готового APK, без пересборки приложения и без дорисовки содержимого.

Отдельный снимок магазина показывает встроенный демокаталог без интернета. Он предназначен для просмотра и не включён в шесть рекомендованных снимков карточки.
