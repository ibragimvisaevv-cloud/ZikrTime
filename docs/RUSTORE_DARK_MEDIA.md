# Тёмные материалы RuStore 0.8.17

Для карточки использовать утверждённую иконку «Купол и горизонт» из `design/widgets-0812/icons/02-dome`. Её экспорт 512×512 RGB находится в `store/rustore/icon-512.png`.

По уточнению владельца в основной папке `screenshots` должны быть семь снимков разных функций: намазы, Коран с переводом, полноэкранное чтение, статистика, тасбих, магазин, мечети. Второй снимок полноэкранного Корана с другой сурой удалён как повтор одного экрана.

Магазин переснят с настоящим онлайн-каталогом, без пометок об отсутствии интернета или демоданных. Мечети показаны с загруженной картой Москвы, выбранным фильтром «Мечети» и ближайшими местами. Эти два снимка входят в основную подборку для RuStore, а не в отдельное превью. Размеры всех семи снимков — 1080×1920, тёмная тема.

Использован уже готовый APK; приложение не пересобиралось. Новые снимки получены обычной навигацией и загрузкой публичных данных в Android 15. Содержимое интерфейса не дорисовывалось.
