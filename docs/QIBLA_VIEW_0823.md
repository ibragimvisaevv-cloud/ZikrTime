# Вид на Каабу

На экране киблы доступна отдельная сцена с реальной фотографией Каабы. Направление и наклон телефона управляют изображением через датчик ориентации. Камера телефона не включается: разрешение CAMERA и зависимости CameraX удалены. В APK отдельно проверяется отсутствие разрешения камеры.

Поворот рассчитывается относительно направления киблы с учётом магнитного склонения. Для вертикально поднятого телефона используется отрицательная ось Z, обычный компас остаётся доступен в прежнем режиме. Датчик отключается при уходе с активного экрана. Движения учитывают общую настройку анимаций. Фотография хранится локально; видео и сетевой поток не используются.

При недостаточной точности датчика или невозможности определить направление экран показывает подсказку и не подтверждает совпадение. Для расчёта используется выбранное местоположение. Точность компаса и ощущение наведения необходимо проверять на физическом телефоне с учётом магнитных помех.
