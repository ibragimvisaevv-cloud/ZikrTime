## Правила обновления и источники в интерфейсе

`SourceInfo` раздельно хранит источник, сведения о переводе, необязательную HTTPS-ссылку, проверку оригинала и проверку конкретного перевода. Статус проверки применяется только к совпадающей версии и непустым проверяющему/области проверки. Без таких данных интерфейс сообщает об отсутствии подтверждённой проверки. Основные сведения доступны офлайн; внешняя ссылка необязательна.

ID никогда не переиспользуется для другого содержания. `contentVersion` увеличивается при существенном изменении смысла вопроса, правильного ответа или схемы вариантов; старое обучение и выбранный ответ этого ID тогда не наследуются. `translationVersion` ведётся отдельно по языкам, а проверка перевода пересматривается при его правке. Изменение локализации интерфейса или перестановка отображаемых ответов не меняет ID/состояние обучения. После редактирования metadata запускается `python tools/quiz/build_quiz.py`.

## Персональное повторение и продолжение занятия

- После правильного ответа без недавно показанной подсказки — интервалы 1, 3, 7, 14, 30 суток; затем 30. Ошибка возвращает на начальный этап с повторением через сутки.
- Повышение этапа возможно только после наступления срока и не раньше суток после объяснения. Ответ сразу после учебной карточки или объяснения не повышает этап. Повторное событие того же ответа игнорируется.
- Короткая очередь: до пяти просроченных вопросов, сначала более ранний срок, при равном сроке — ошибка. Удалённые/существенно изменённые вопросы отфильтровываются.
- Сроки хранятся в миллисекундах UTC; смена часового пояса не меняет интервал. Перевод часов назад не переносит время сохранённого ответа в прошлое и не создаёт отрицательный интервал. Это локальная адаптивная логика, не защищённый серверный экзамен.
- Отдельный сценарий «Повторить» бонусов не даёт. Обычные/блокирующие раунды используют существующие бонусные минуты с идемпотентной защитой Store по ID сеанса, корректно отвеченным ID и времени.
- В `learning_state_v1` сохраняются реальные ID/версии вопросов, текущая карточка и вопрос, порядок вариантов, выбранный исходный индекс, этап и итог. Перезапуск процесса не начинает вместо этого другой вопрос. Смена языка использует те же ID и канонические индексы вариантов.
- Обучение и продолжение занятия работают при отключённом личном прогрессе. Открытие карточки фиксирует только факт показанной подсказки для адаптивного алгоритма, не «изученную тему». Сброс обучения не сбрасывает бонусный защитный журнал и личную статистику; сброс статистики не очищает обучение.

Автоматические тесты покрывают интервалы, ошибки, немедленный повтор, изменение времени/версии, удаление вопросов, ограничение очереди и восстановление выбранного ответа/карточки/итога из JSON. Содержательная проверка специалистом остаётся внешним ограничением для всего существующего банка и его переводов.
