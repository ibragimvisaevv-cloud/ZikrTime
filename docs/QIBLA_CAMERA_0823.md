# Кибла через камеру

Режим открывается кнопкой на экране киблы. CameraX используется только для предпросмотра с привязкой к жизненному циклу. Датчик ориентации работает только на видимом активном экране. Для камеры берётся направление отрицательной оси Z устройства с поправкой магнитного склонения. Фото появляется в направлении киблы при достаточной точности датчика.

В приложение включена предоставленная Wikimedia миниатюра 960×540. При отображении используется обрезка по размеру карточки, лицензия изображения сохранена. Ссылка на авторство доступна на экране камеры.

Камера запрашивается при открытии режима. Съёмка фото, видео и отправка кадров отсутствуют. Устройство без датчика или с низкой точностью показывает подсказку, совпадение направления не заявляется. Для направления требуется выбранное действительное местоположение. Проверка на физическом устройстве необходима для оценки его магнитных помех и фактической точности.
