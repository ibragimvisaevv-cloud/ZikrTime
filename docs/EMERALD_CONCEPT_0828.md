# Изумрудное оформление: этап 1

8 ноября 2026. База: восстановленная 0.8.28, `362244c46133feb9b7ef3d55cc716531a8b521f8`. Эта ветка создана от базы и содержит только документацию. Android-исходники не менялись.

## Обязательный порядок

1. Показать концепции и сравнение. **Ожидать явного одобрения владельца**.
2. После одобрения реализовать главную и один внутренний экран, показать настоящие кадры и прокрутку.
3. Только после отдельного одобрения образца распространять систему на остальные экраны.
4. Проверить затронутые сценарии, обе темы, 8 языков, маленький экран, крупный текст и обновление с данными. Публикация и merge требуют отдельного поручения.

## Направление

Сохранить сильные стороны0.8.28: фотографические сцены, исламскую атмосферу, глубину, перекрытие пейзажа передней панелью при прокрутке. Палитра: глубокий изумрудный/нефрит, светлый текст, небольшие золотистые акценты. Не возвращать отвергнутую0.8.29 и «Ритм и пауза», не заменять оформление однотонными экранами. Светлая тема сохраняется.

Уточнение этапа2: реальные отображаемые вкладки - Намаз / Знания / Магазин / Лимиты / Настройки (через MainActivity/clarityCopy); FOCUS/MORE - внутренние enum. Не переносить вкладки, даты, цены, прогресс и данные из генерации. Исходные религиозные ресурсы, подпись, applicationId, функции и пользовательские данные сохранять.

## Результат этапа

Подготовлены две сгенерированные доски (7 областей): главная, чтение/аудио Корана, тасбих, магазин, будильник, виджеты, первый запуск. Полная карта состоит из75 строк и проверена по исходникам. Ни одна новая реализация пока не согласована и не выполнена.

Четыре базовых настоящих кадра берутся из встроенной инструкции: welcome-1.webp, quran-2.webp, tools-2.webp, shop-1.webp. Три сняты на0.8.27 и документированно включены в0.8.28, панель Корана снята на ранней0.8.28. Хеши всех30WebP сверены с guide-evidence-0828. На старых снимках видны названия Лимиты/Настройки. Не называть их свежей съёмкой восстановленного APK. Для будильника, виджетов, первого запуска свежие кадры0.8.28 не получены.

## Ограничения макетов

- Область Корана обозначена текстовым placeholder; священный текст генератором не воспроизводился. В реализации использовать только исходные данные.
- Главная показана фрагментом: расписание, отметки, источник, отсчёт и прочие действия должны оставаться.
- Панель аудио в концепции раскрыта; режим чтения должен сохранять большую область текста. Стоп, предыдущий/следующий аят, полная сура, офлайн, копирование, настройки чтения, заметки и закладки остаются. Нарисованный включённый переключатель не задаёт default.
- В тасбихе сохранить также безлимитную цель и накопленные результаты; безопасный сброс.
- Пустая выдача магазина в рисунке является отдельным образцом состояния; не показывать её вместе с найденными карточками. ALI.PERFUME взят из исходного снимка, это не подтверждение текущего ассортимента.
- Геометрия виджетов условна; реальную поддержку2×1/4×1/2×2/4×2 проверять в лаунчере. Системные уведомления не подменяются рисованным экраном.
- Светлая концепция, полный режим чтения, реальные переходы и удобство управления пока не показаны/не проверены.
