# Новая главная и тасбих — Android 0.8.3

Тестовая сборка с натуральной архитектурой и небом, четырьмя периодами суток по местному времени города и движущимися каменными бусинами тасбиха. Сохранены прежние разделы, настройки и восемь языков. Постоянные фоновые эффекты на этих двух экранах отключены.

## Установить

[Скачать APK для Android](https://github.com/ibragimvisaevv-cloud/ZikrTime/releases/download/v0.8.3-natural.1/ZikrTime-0.8.3-natural.apk).

Откройте APK на телефоне и разрешите установку из браузера. Поверх установленной 0.8.3 можно обновляться без удаления: сертификат подписи прежний. AAB нужен для дальнейшей подготовки магазина, для установки выбирайте APK.

## Что проверено

- 18 unit-тестов; проверка восьми языков; Lint: 0 ошибок, 52 предупреждения, 4 информационных замечания.
- 16 реальных снимков Android 15: четыре периода, светлая/тёмная тема, узкий экран и текст 130%.
- 40 нажатий дали ровно +40; смена целей, сброс, смена фразы и сохранение после перезапуска прошли.
- APK 52 003 510 байт (+0,43%); AAB 30 190 077 байт (+0,74%) к сопоставимой release-базе.
- На одном debug-эмуляторе: медиана кадра 53 → 16 мс; новых кадров за 5 секунд покоя 214 → 0. Пропуски кадров сохраняются; плавность на физическом телефоне и расход батареи ещё не подтверждены.
