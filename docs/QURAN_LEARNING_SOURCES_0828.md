## Поаятное чтение Аль-Афаси

Используются **те же 114 файлов MP3Quran**, которые уже перечислены в
`assets/quran_audio/alafasy.json`. Дополнительных записей в APK нет, отдельная
копия каждого аята не требуется: воспроизводится ограниченный временной
отрезок суры. Поэтому явно скачанная сура подходит и для прослушивания её
отдельных аятов. Временный кэш остаётся ограниченным и не гарантирует, что вся
сура доступна без сети.

Первичные источники:

- [Документация MP3Quran v4](https://docs-staging.mp3quran.net/), раздел
  `Sync with ayah and word timings`: строки `[ayah, start_ms, end_ms]`,
  нулевой номер означает отдельную басмалу, `-1` — истиазу.
- [Официальный список чтений с таймингами v3](https://mp3quran.net/api/v3/ayat_timing/reads):
  `id=123`, Мишари Аль-Афаси, Хафс от Асыма, 114 сур, адрес
  `https://cdn.mp3quran.net/audio/mishary-alafasy/r1/`.
- [Каталог файлов v4](https://api-staging.mp3quran.net/v4/recitations/mishary-alafasy/r1/surahs?all=true).
- Шаблон таймингов:
  `https://api-staging.mp3quran.net/v4/recitations/mishary-alafasy/r1/surahs/{surah}/ayah-timings`.
- [Разрешение MP3Quran для посетителей и разработчиков](https://www.mp3quran.net/eng/privacy),
  раздел Copyrights. Оно уже зафиксировано в заметке 0.8.27; не обозначать
  записи как public domain или Creative Commons.

Данные получены с официального **staging API** издателя и зафиксированы локально;
приложение не зависит от доступности этого API во время работы. Версия каталога
во всех ответах: **668**. Исходные 114 ответов сохранены без изменения под
`tools/quran/source-evidence/0828/ayah-timings/`, их URL, размеры и SHA-256 — в
`timing-provenance.json`.

Скрипт `tools/quran/import_ayah_timings_0828.py` проверил:

- наличие всех 114 сур и **6 236** уникальных номеров аятов по существующему
  защищённому манифесту Корана;
- `complete=true`, положительные длительности, возрастающие интервалы без
  пересечений, отсутствие недостающих и неожиданных номеров;
- конец каждого интервала внутри длительности официальной записи с допуском
  в одну секунду из-за округления длительности в каталоге;
- точное совпадение URL и размеров всех 114 оригинальных MP3 с каталогом 0.8.27.

Это проверка происхождения, покрытия и структуры данных, а не утверждение о
ручном прослушивании каждого аята. Хеши MP3 в официальном каталоге сохранены
как метаданные издателя; полные записи повторно не скачивались для хеширования.

**Особенность 37:151:** источник содержит две соседние части одного аята:
`1218520–1228762` и `1229066–1231466` мс. Для выбора аята они объединены в
один отрезок `1218520–1231466` мс; оригинальные строки сохранены в исходном
ответе. Воспроизводятся обе части исходной записи. Счётчик пользовательских
повторов считает проигрывания этого полного отрезка. Никакие другие номера
не объединялись, пробелы в покрытии не заполнялись предположениями.

Басмала в Аль-Фатихе — нумерованный аят **1:1**. Отдельные строки `0` и `-1`
в других сурах не превращаются в дополнительные нумерованные аяты.

## Русская транскрипция: подтверждённый результат поиска

редакторское происхождение и разрешение распространения в приложении, **пока
не найден**. Не заменять его машинной конвертацией латиницы, не собирать
недостающие аяты моделью и не называть случайный открытый файл «проверенным».

## Сравнение с Quran Majeed и офлайн-аудио

Официальная [страница Pakdata в Google Play](https://play.google.com/store/apps/details?id=com.pakdata.QuranMajeed)
перечисляет повтор аята/суры, число повторов, интервал и скорость. Это
ориентир поведения, а не разрешение копировать интерфейс или материалы.
У издателя также есть [инструкция скачивания аудио](https://pakdata.com/qm-audio-download-instructions).

Для воспроизведения записи без сети её байты уже должны находиться на телефоне:
в поставке приложения, предварительной загрузке, скачанном пакете или кэше.
Отсутствие отдельного нажатия «Скачать» не доказывает отсутствие загрузки.
Сжатие уменьшает размер, но не убирает необходимость хранения. Какой именно
вариант случился у владельца в Quran Majeed, без проверки его устройства
не установлено. Автоматически скачивать весь Коран из-за этого предположения
не требуется и в этой задаче не запрошено.
