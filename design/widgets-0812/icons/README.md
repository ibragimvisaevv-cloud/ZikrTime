# Три варианта иконки ZikrTime

Иконка установленного приложения пока сохранена. Эти варианты — для выбора.

1. **Арка света — рекомендую.** Крупная архитектурная арка и тёплый проём связывают значок с утверждённой главной. Сохраняет узнаваемость в 24–48 px.
2. **Купол и горизонт.** Прямой архитектурный знак на тёплом светлом фоне. Самая заметная светлая плашка среди иконок.
3. **Ритм зикра.** Несимметричная петля тасбиха с подвесом. Подвес отличает её от индикатора загрузки.

Каждая папка содержит редактируемые SVG и Android VectorDrawable: фон, знак, monochrome и пример adaptive.xml. Холст 108 dp; ключевые формы внутри центральной безопасной окружности. После выбора слои будут подключены к launcher и splash; сейчас они не подключены к ресурсам приложения.

Превью рабочего стола — **дизайнерские макеты**, не скриншоты внедрённой новой иконки. Примеры масок: круг, скруглённый квадрат и более прямоугольный силуэт. Размеры 24, 32, 48 px. Собственный шрифт для значка не требуется.
