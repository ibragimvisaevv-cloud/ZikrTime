Снимки и журнал проверки: [review](review/README.md). Запись отсчёта показывает реальные изменения native-интерфейса. Превью трёх исходных вариантов иконки в `icons/*-preview.jpg` — дизайнерские макеты, а не снимки установленного приложения.

Платформа визуальной проверки: Android 15 / API 35, эмулятор со штатным лаунчером, 1080×1920 / 420 dpi. Существующие имена провайдеров NextPrayerWidget, TodayWidget, TasbihWidget и ScreenTimeWidget сохранены. Проверка обновления использует одинаковую одноразовую тестовую подпись обеих версий; она проверяет сохранение данных и ID, а не подпись дистрибутива.

На физических телефонах и лаунчерах Samsung/Xiaomi проверка не проводилась. API 26–34 поддержаны кодом, но этот набор снимков подтверждает API 35. Отдельная проверка полного закрытия приложения на длительный период в Doze не проводилась. Режим без права на точные события предусмотрен как абсолютное время с действием обновления; принудительный отказ в этом разрешении в данном прогоне не моделировался.

Подтверждения разделены по источникам: внешний вид финального APK — прогон 41025914614; сценарии данных — 41025421561 (тот же механизм расчёта и событий); нажатия и тасбих — 41028419737; изменение размера и жизненный цикл — 41030076563. После проверки данных изменялись только превью настройки и оформление вспомогательных виджетов. В старых журналах сохранены ошибки автоматизации; они не удалены и не переименованы в успешные проверки.

Следование системной теме реализовано, но отдельное переключение темы системы в финальном прогоне не зафиксировано. Полный визуальный обход всех восьми переводов и всех форматов на маленьком экране остаётся за пределами этой проверки.

Старый lifecycle-тест перезагрузки читал сохранённую отметку времени; его положительный результат сам по себе недостаточен. Его заменяет отдельный прогон 41031874367: новая отметка отрисовки после загрузки и видимое время в лаунчере без запуска приложения.
