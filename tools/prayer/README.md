# Региональные календари

Шесть полей времени в TSV идут в порядке «фаджр, восход, зухр, аср, магриб, иша». Город и гражданская дата входят в ключ. В таблицах отсутствуют переносы значений между календарными годами. Вечерний фаджр относится к предшествующим гражданским суткам, а иша после полуночи — к следующим. В расписании сохраняется дата строки издателя.

| Источник | Проверка периода и места |
|---|---|
| [Грозный, ДУМ ЧР](https://dumchr.ru/) и [публичный интерфейс Assolat](https://assolat.ru/docs) | Месячный JSON содержит город, год, месяц и дату каждой строки. Данные за 6 ноября 2026 сверены по всем шести полям с ДУМ ЧР. Другие города ЧР требуют отдельного подтверждения. |
| [ДУМ Татарстана](https://dumrt.ru/ru/) | CSV из виджета Казани содержит гражданские даты с годом. Используются начало фаджра и отдельный столбец зухра. |
| [Муфтият Дагестана](https://muftiyatrd.ru/vremya-namaza) | Публичный виджет использует городские массивы из 365 строк без года. Подтверждено сопоставление с календарём 2026. Для нового года требуется повторная проверка публикации. |
| [ДУМ Башкортостана](https://dumrb.com/) | Месячный ответ собственного сайта содержит название города, год и месяц. Число строк должно совпадать с длиной месяца. Координаты городов проверены по методу GetSupportedCities. |
| [ДУМ Казахстана](https://namaz.muftyat.kz/ru/namaz/api/) | В запросе используются координаты из справочника издателя. Проверяются название возвращённого города и год. В строках есть даты. |
| [ДУМ Кыргызстана](https://muftiyat.kg/ru/calendar/api/) | Публичный API принимает идентификатор места и границы дат. Проверяются возвращённый идентификатор и гражданские даты. |
| [ЦДУМ России](https://www.cdum.ru/time-namaz/Spb.php) | Год подписан рядом с городом в оглавлении. Импортер проверяет название страницы, заголовки колонок, месяц, каждое число и день недели. Число 2015 в старых адресах страниц издателя относится к имени файла. |
| [ДУМ Нижегородской области](https://islamnn.ru/namazy/2026/nn2026.pdf) | PDF содержит отдельную страницу на каждый месяц с явно указанным годом, днями недели и столбцами зенита и зухра. |
| [ДУМ Саратовской области](https://dumso.ru/raspisanie) | Публикуется текущий месяц для Саратова. Год и месяц проверяются по датированной ссылке календаря, названию таблицы и дням недели. Указанное внизу время совершения в мечети отделено от зухра в таблице. |

## Обновление из API

В корне репозитория установите переменные окружения и запустите задачу Gradle. Для Windows используется gradlew.bat. Используйте новый путь для каждого кандидата на выпуск.

~~~sh
export ZIKR_PRAYER_EXPORT_FILE=/tmp/regional-2026-candidate.tsv
export ZIKR_PRAYER_EXPORT_YEAR=2026
./gradlew :app:testDebugUnitTest --tests '*RegionalCalendarExportTest' --rerun-tasks
~~~

Тест с указанными переменными вызывает те же адаптеры и валидаторы, что Android. Без переменных он пропускается. Для выборочного обновления можно установить ZIKR_PRAYER_EXPORT_CITIES в список идентификаторов через запятую. Такой файл содержит только выбранные города. Пустой месяц означает отсутствие опубликованных дат. При ошибке сети или несовпадении схемы сохранение прерывается. Сверьте изменения с оригиналами и включайте в поставку даты, подтверждённые издателем.

## Импорт документов

~~~sh
python -m pip install lxml pypdf
python tools/prayer/import_published.py 2026 /tmp/calendars-2026 /tmp/published-2026-candidate.tsv
~~~

Скрипт сохраняет исходные HTML и PDF в рабочую папку и повторно использует сохранённые копии. Храните отдельную папку для каждого года. Для восстановления нескольких предыдущих месяцев Саратова поместите страницы соответствующих месяцев в неё под именами saratov-YYYY-MM.html. Проверяйте ссылки и новый год перед импортом в следующем выпуске. Незнакомая схема, другой город или расхождение с днём недели останавливают импорт. Соседние дни с пересекающимися временами и строки с противоречивым порядком исключаются. Список выводится при импорте.

На 6 ноября 2026 в regional.tsv 13 140 строк для 36 городов, в published-2026.tsv 6 956 строк для 20 городов. Для Саратова доступен ноябрь. Для Салехарда девять дат исключены из-за пересекающихся или противоречивых интервалов. Город Москва ведётся отдельным механизмом приложения.
