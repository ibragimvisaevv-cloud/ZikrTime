# Зикр-тайм — первая версия для Android

«Сначала зикр, потом скролл». Приложение показывает время намаза, ограничивает соцсети дневным лимитом и даёт заработать дополнительные минуты ответами на вопросы об Исламе.

## Что умеет версия 0.1

- **Время намаза** для выбранного города или по геолокации. Расчёт идёт на телефоне, без интернета. Шесть методов расчёта (Всемирная исламская лига, ISNA, Египет, Умм аль-Кура, Карачи, Диянет) и выбор мазхаба для аср-намаза. Для северных городов (Москва летом и т. п.) применяется правило высоких широт.
- **Уведомления** о наступлении времени каждого намаза.
- **Дневной лимит на соцсети.** Пользователь выбирает приложения и лимит (10–180 мин). Когда время вышло, соцсеть закрывается и появляется экран «Лимит исчерпан».
- **Разблокировка задачами.** 3 правильных ответа = +10 минут, максимум +60 минут в день.
- **Блокировка во время намаза.** После азана выбранные соцсети закрыты 5–30 минут. Кнопка «Я совершил намаз» сразу снимает блокировку и отмечает намаз.
- **Серии дней:** «Серия знаний» (дни с пройденным раундом викторины) и «Серия намазов» (дни, когда отмечены все пять намазов).
- **83 вопроса** в 6 темах: Коран, пророки, сира, основы и фикх, арабские слова, «продолжи аят».
- Дата по хиджре на главном экране, светлая и тёмная тема.

## Как собрать и установить

### Вариант 1. Android Studio на компьютере

1. Установите [Android Studio](https://developer.android.com/studio) (бесплатно).
2. Распакуйте архив и откройте папку `ZikrTime` через **File → Open**.
3. Дождитесь, пока Android Studio скачает всё нужное (первый раз — несколько минут). Если появится предложение обновить Gradle или плагин Android — можно согласиться.
4. Подключите телефон по USB с включённой «Отладкой по USB» (Настройки → О телефоне → 7 раз нажать «Номер сборки» → в «Для разработчиков» включить отладку) и нажмите зелёную кнопку **Run ▶**.

### Вариант 2. Без Android Studio, через GitHub

В проекте уже есть файл `.github/workflows/build.yml`. Если загрузить проект в репозиторий на GitHub, сборка запустится сама. Через 5–10 минут во вкладке **Actions → последняя сборка → Artifacts** появится архив `ZikrTime-apk` с файлом `app-debug.apk`. Его можно скачать на телефон и установить (Android попросит разрешить установку из этого источника).

## Первый запуск на телефоне

1. Выберите город или нажмите «Определить по геолокации». Разрешите уведомления.
2. Вкладка **Контроль** → выдайте два разрешения:
   - **Доступ к истории использования** — найдите «Зикр-тайм» в списке и включите.
   - **Служба «Зикр-тайм»** (специальные возможности) — откройте «Скачанные приложения» → «Зикр-тайм» → включите.
     На Android 13 и новее для приложений, установленных не из Google Play, этот переключатель может быть серым. Тогда: **Настройки → Приложения → Зикр-тайм → меню ⋮ → «Разрешить ограниченные настройки»**, затем повторите.
3. Включите «Ограничивать соцсети», выберите лимит и приложения.
4. По желанию во вкладке **Настройки** разрешите «точное время» уведомлений (Android 12+).

Проверить быстро: поставьте лимит 10 минут, посидите в выбранной соцсети — через 10 минут она закроется.

## Устройство проекта

```
app/src/main/java/com/zikrtime/app/
  prayer/       расчёт времени намаза, будильники и уведомления
  screentime/   учёт времени в соцсетях, служба блокировки, экран блокировки
  quiz/         загрузка вопросов
  data/         настройки и прогресс (хранятся только на телефоне), города, серии
  ui/           экраны: главная, задачи, контроль, настройки, выбор города
app/src/main/assets/questions.json   банк вопросов
tools/build_questions.py             исходник банка вопросов (редактировать здесь и запускать)
```

## Как добавить вопросы

Откройте `tools/build_questions.py`, добавьте строку по образцу (правильный ответ — всегда первый вариант, в приложении варианты перемешиваются) и запустите `python3 tools/build_questions.py`. Можно и сразу править `questions.json`.

Перед публикацией вопросы и пояснения стоит показать знающему человеку — имаму или преподавателю.

## Что важно сделать перед публикацией в Google Play

- Создать собственный ключ подписи (сейчас release подписывается отладочным ключом).
- Google Play строго проверяет приложения со службой специальных возможностей: понадобится заполнить декларацию и показать видео работы. В приложении уже есть экран с объяснением, зачем нужна служба.
- Политика конфиденциальности (приложение ничего не отправляет в интернет — это стоит прямо указать).

## Проверка расчёта времени намаза

Формулы сверены с открытой библиотекой Adhan на 480 значениях (5 городов, 4 даты, 2 метода, 2 мазхаба): 448 совпали до минуты, остальные расходятся на 1–2 минуты. Расписание мечети в конкретном городе может отличаться — там часто добавляют поправки «на всякий случай».
