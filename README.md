# Зикр-тайм (ZikrTime)

«Сначала зикр, потом скролл». Исламский помощник: точное время намаза, громкий будильник на фаджр с азаном, викторина с пояснениями, кибла, тасбих и дневной лимит на соцсети, который можно продлить ответами на вопросы.

Языки: русский, английский, узбекский, таджикский, казахский, кыргызский, азербайджанский, турецкий.

## Установка на Android

1. Если стояла версия 0.1 или 0.2 — удалите её один раз (у новых версий постоянная подпись, дальше обновления ставятся поверх).
2. Откройте на телефоне страницу [последнего выпуска](https://github.com/ibragimvisaevv-cloud/ZikrTime/releases/latest), скачайте файл `ZikrTime-….apk` и откройте его. Android попросит разрешить установку из браузера — разрешите.

### Первая настройка

- **Язык и город** выбираются при первом запуске; город можно определить по геолокации.
- **Будильник на фаджр**: «Ещё» → «Будильник на фаджр». Выберите, за сколько минут до фаджра будить (0–120), дни недели и звук. Будильник играет азан на максимальной громкости, пока его не выключат вручную; по желанию — «ответить на вопрос, чтобы выключить». Кнопка «Проверить будильник» включит его через 10 секунд. Разрешите уведомления, «будильник на весь экран» и «точное время», если приложение попросит.
- **Лимит соцсетей**: вкладка «Фокус» → доступ к статистике использования и один из двух способов блокировки:
  - **Способ 1 «Поверх других приложений»** — проще всего, телефон не считает его опасным;
  - **Способ 2 «Служба Зикр-тайм»** — на Android 13+ для приложений не из Google Play переключатель бывает серым: «Сведения о приложении» → ⋮ → «Разрешить ограниченные настройки».
- **Время намаза**: «Ещё» → «Время намаза». По умолчанию — метод ДУМ РФ и загрузка времени с aladhan.com; без интернета время считается на телефоне. Есть поправки ±30 минут под расписание вашей мечети.

## iPhone

В папке `ios/` — отдельное приложение на SwiftUI с теми же вопросами, городами, переводами и азаном.

Что работает: время намаза (aladhan.com или расчёт), уведомления, будильник на фаджр (на iOS 26+ — системный будильник AlarmKit, звонит даже в беззвучном режиме; на старых iOS — серия уведомлений с азаном), викторина с пояснениями, кибла по компасу, тасбих, 8 языков. Лимит соцсетей на iPhone требует разрешения Apple на «Экранное время» и появится позже.

Как поставить на телефон: любое приложение для iPhone нужно подписать сертификатом Apple.
- **Бесплатно**: тестовая сборка без подписи (`.ipa` в выпусках с пометкой iOS) ставится через Sideloadly или AltStore с компьютера (Windows или Mac) под вашим Apple ID. Подпись живёт 7 дней, потом приложение нужно переподписать.
- **Как обычное приложение**: Apple Developer Program (99 $ в год) → TestFlight для тестировщиков → App Store.

## Как устроен проект

```
app/                         Android-приложение (Kotlin, Jetpack Compose)
  src/main/java/…/prayer/      расчёт и загрузка времени намаза, уведомления
  src/main/java/…/alarm/       будильник на фаджр (служба, экран будильника)
  src/main/java/…/screentime/  учёт времени в соцсетях и блокировка
  src/main/java/…/ui/          экраны
  src/main/assets/quiz/        вопросы на 8 языках (общие с iPhone)
  src/main/assets/cities.json  города на 8 языках (общие с iPhone)
ios/                         iPhone-приложение (SwiftUI), проект собирается XcodeGen из ios/project.yml
shared/audio/                азан для iPhone (уведомления и будильник)
tools/i18n/<язык>.py         все строки интерфейса → python3 tools/i18n/build_strings.py (Android)
                                                   → python3 tools/ios/build_strings.py (iPhone)
tools/quiz/<язык>.py         вопросы викторины → python3 tools/quiz/build_quiz.py
tools/ci/                    проверки в GitHub Actions (переводы, эмулятор, скриншоты)
```

## Сборка и проверка

Всё собирается в GitHub Actions при каждом изменении:

- **Android**: тесты (расчёт намаза сверяется с библиотекой Adhan и с aladhan.com, кибла, вопросы на всех языках), сборка APK, запуск на эмуляторе и скриншоты всех экранов на всех языках — в ветке `ci-artifacts`. Выпуск APK — когда в сообщении коммита есть `[release]`. `[no-emu]` пропускает эмулятор для мелких правок.
- **iPhone**: проверка логики на Linux, сборка в Xcode, скриншоты из симулятора — в ветке `ci-artifacts-ios`. Сборка `.ipa` — по `[release-ios]` в сообщении коммита.

Локально Android-проект открывается в Android Studio (папка репозитория → File → Open).

## Источники и лицензии

- Время намаза: [aladhan.com](https://aladhan.com) и алгоритм PrayTimes.
- Азан: «Beautiful adhan» с Wikimedia Commons, CC0 (общественное достояние).
- Арабский шрифт: Amiri, SIL Open Font License 1.1.
- Вопросы составлены по известным фактам о Коране, пророках, сире и основах Ислама. Это не фетва: по вопросам религиозных предписаний обращайтесь к учёным. Переводы стоит проверить носителям языков.
