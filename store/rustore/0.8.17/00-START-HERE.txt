СТАТУС
Релизная сборка 0.8.17 (29) подготовлена, но пока НЕ ПОДПИСАНА прежним ключом. APK для загрузки в магазин в этот архив не включён. Тестовый 0.8.17-test.apk из чата для RuStore не подходит.

ЧТО НУЖНО СЕЙЧАС
В репозитории GitHub ibragimvisaevv-cloud/ZikrTime откройте:
Settings → Secrets and variables → Actions → Repository secrets → RELEASE_KEY_PASSWORD → Edit.
Сохраните прежний пароль Android-ключа выпуска. Сейчас проверка определяет в этом поле GitHub-токен, который не расшифровывает ключ.
Ссылка: https://github.com/ibragimvisaevv-cloud/ZikrTime/settings/secrets/actions
Сам пароль в чат не отправляйте. Новый ключ создавать не нужно: для обновления пользователей нужен прежний сертификат.
После исправления сообщите «пароль обновил». Подготовлен отдельный процесс подписи уже собранного APK без пересборки приложения.

ПОСЛЕ ПОЛУЧЕНИЯ ПОДПИСАННОГО APK
1. В существующей карточке приложения нажмите «Загрузить версию».
2. Выберите ZikrTime-0.8.17-RuStore.apk. Дождитесь проверки файла: com.zikrtime.app, версия 0.8.17, код 29. У опубликованной версии код 14.
3. Вставьте 01-whats-new-ru.txt в «Что нового». Описания из 02 и 03 подготовлены для обновления карточки.
4. Загрузите новые скриншоты по порядку имён файлов. Существующие название, категории и контакт разработчика можно сохранить.
5. Обновите публичную политику и соответствующие сведения о данных. Ссылку на политику из текущей карточки сохраните, если адрес не меняется.
6. Добавьте пояснения модератору из файла 04. Основные функции доступны без аккаунта.
7. Перед модерацией проверьте установку подписанной версии поверх версии из RuStore на телефоне: сохранение города и настроек, запуск Корана, будильник и необходимые разрешения.
8. Отправьте версию на модерацию. Отправка и публикация в RuStore ещё не выполнялись.
